# Garage Studio implementation

The user's later native iOS direction supersedes the initial Night Session palette. A final accent pass adds restrained electric-blue-to-violet gradients while keeping the neutral foundation. Implementation and production evidence are described in [VERIFICATION.md](VERIFICATION.md).

1. **Shared visual foundation.** Black/charcoal/white foundations, blue/violet gradient primaries and softly tinted active tabs, platform system typography (SF on Apple devices), Lucide icons, consistent rounded controls, blue keyboard focus and responsive five-tab navigation. Decorative pink/mint accents are removed; semantic error/warning colors remain.
2. **Personal entry and home.** A pre-React startup presents a verified local thumbnail of the selected motorcycle, a horizontal pass and a reduced-motion alternative. Optional personalization never delays readiness. Owner-bound caching, account changes, erasure, storage denial and private-preview isolation are covered by focused checks.
3. **Garage and account.** A clear machine showcase, readable stats and equipment cards, native account sections, and local portrait import with preview/cancel/save. The exact selected D1 motorcycle is reused; two built-in generations use the original helmet/suit photographs. Zero Gemini calls. Private assets stay outside Git and production output. Reactive machine/equipment collections show first-sync arrivals without resetting selected identity, drafts or import previews.
4. **Every current route.** Harmonize rides, Analysis, daily outfit, expenses, preparation, season, budget, maintenance, photo/video views and recap. Preserve the 47 integrated upstream commits, including outfit genre selection, credit controls and collapsible sections. Saved imported portraits win consistently over development overrides.
5. **Evidence and production delivery.** Two visual directions with review/correction loops, 390/768/1440 captures, 203 unit checks and 32 existing browser suites. Startup, confidentiality and offline checks are complemented by an isolated live-account verification. Restore the production sync binding, deploy the missing video rule, publish the three owner-scoped portraits and verify their original photos remain intact.
6. **First synchronization.** A mounted garage and equipment list must update when the account data arrives on a fresh device. Keep the selected motorcycle stable by ID and preserve unsaved portrait previews during remote updates.

Each visual story follows [design-spec.md](design-spec.md) and [tokens.json](tokens.json), preserves database behavior, and covers applicable empty/loading/error and populated states. The startup cache is disposable presentation data; the SQLite database and original media remain authoritative. No source photograph is silently overwritten.
